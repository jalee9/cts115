The Big Picture

  • Data are raw facts. Information is data in context that answers a question. Knowledge is insight from experience.
  • Most business data lives in relational databases: tables of rows and columns linked by keys and queried with SQL.
  • Data comes from transaction systems, loyalty programs, enterprise software, surveys, and outside data aggregators.
  • Many firms are “data rich, information poor.” Data warehouses, data lakes, and ETL pull scattered data together so it can be analyzed.
  • BI tools, dashboards, and data mining turn data into decisions. Walmart shows how a data-driven value chain built the world's largest retailer.

Section 11.1

Data and a New Age of Decision-Making

Cheap storage, fast computers, standardized data, and easier software mean managers can now make decisions based on facts, not just gut feel. Analytics uses data, statistics, and models to drive decisions. Firms collect Big Data, datasets too large and messy for ordinary tools.

Real-world example · Dynamic pricing for shows and games

Broadway theaters and sports teams use data to change ticket prices in real time based on demand, the opponent, the weather, and how fast seats are selling. That's dynamic pricing. Stores also use Bluetooth beacons to detect shoppers' phones and send location-based offers.

Section 11.2

Data, Information & Knowledge

How data is organized

A database is a table or a set of related tables, managed by a DBMS. In a relational database, tables are linked by shared keys.

A “Students” table. Each row is a record, and each column is a field.
STUDENT_ID (key)First nameLast nameMajor
1001AnaRiveraBusiness
1002JordanLeeNetworking
1003SamPatelWeb Development
Why use an ID instead of a name?

Two students can share a last name, but each has exactly one STUDENT_ID. A unique key (the primary key) lets an “Enrollment” table point back to the right student. When it appears in that other table, it's called a foreign key.

What SQL looks like

SQL (Structured Query Language) is the standard way to ask a database questions:

SELECT first_name, last_name
FROM Students
WHERE major = 'Business';

A database administrator (DBA) designs, secures, backs up, and maintains databases.

Section 11.3

Where Does Data Come From?

Internal

Transaction processing systems

A TPS records every transaction, such as a cash register sale, an ATM withdrawal, or a return.

Internal

Loyalty programs

Rewards in exchange for tracking. Your purchases get linked to you.

Internal

Enterprise software

CRM, SCM, and ERP systems capture data across the value chain.

Internal

Surveys

Ask customers directly, although people don't always do what they say.

External

Data aggregators

Firms that collect and resell data, such as credit histories or demographics. If rivals can buy the same data, it isn't an advantage.

Real-world example · The Starbucks app

The Starbucks Rewards app combines payment, ordering ahead, and rewards. It gives Starbucks detailed data on what each customer buys, when, and where. Starbucks uses that data for personalized offers and smarter store planning.

Section 11.4

Data Rich, Information Poor

Many firms have mountains of data but still can't answer basic questions. Why?

  1. Incompatible systemsDifferent departments use different software that can't easily share data.
  2. Legacy systemsOlder systems are hard to connect to new technology. They can trap valuable data like a prison.
  3. Operational databases are busyRunning heavy analysis on the live sales database could slow down checkout for customers.
  4. Privacy lawsRules limit how some data can be used, shared, or kept.
Real-world example · Airbnb

Airbnb studies millions of bookings to suggest prices to hosts based on location, season, and local events. Hosts earn more, and Airbnb's marketplace works better.

Section 11.5

Data Warehouses, Data Marts & Data Lakes

Storage for analysis
TermWhat it is
Data warehouseCombined, cleaned databases built to support decisions across the whole firm
Data martA smaller warehouse focused on one problem or department, like marketing
Data lakeStores structured and raw, unstructured data (text, images, logs) for flexible Big Data analysis. Tools like Hadoop help manage it.
Data cloudA cloud service (like Snowflake) that combines data from many sources for analysis
OLAP / data cubePre-summarized data that allows very fast “slice and dice” reporting
Why it matters to you · Data careers

Firms struggle to find people who can clean, analyze, and explain data. Data science and analytics skills are in high demand, and they matter just as much for preparing clean data to train AI.

Section 11.6

The Business Intelligence Toolkit

Reports

Canned vs. ad hoc

Canned reports arrive on a regular schedule in a fixed format. Ad hoc tools let you build custom reports when you need them.

Visuals

Dashboards

A heads-up display of key metrics, like a car's dashboard for a business, built with data visualization.

Code

Python, R & SQL

Programming languages that analysts use to query, model, and chart data.

AI

Data mining & machine learning

Computers search large datasets for hidden patterns and build predictive models.

Data mining is used for customer segmentation, fraud detection, market basket analysis (what's bought together), predicting which customers will leave, and personalizing omnichannel experiences.

Watch out · When models fail

Models can mislead when the data is biased or dirty, when the world changes and the past no longer predicts the future, or when the model is over-engineered (fit so tightly to old data that it fails on new data). Correlation isn't causation.

Section 11.7 · Case

Case: Data and the Rise of Walmart

Walmart became the world's largest retailer by running an incredibly efficient, data-driven value chain.

Data

Sharing with suppliers

Walmart's Retail Link system shows suppliers their sales at each store, so they can restock exactly what's needed.

Data

Mining prowess

Walmart famously found that before hurricanes, sales jump for flashlights, and also for strawberry Pop-Tarts.

Tech

Robots & VR

Automated distribution centers, shelf-scanning robots, and VR training for employees.

Growth

E-commerce & ads

Walmart is betting big on online sales and a fast-growing advertising business powered by its shopper data.

Challenges ahead

Walmart faces Amazon online, discount rivals in stores, and pressure over wages and working conditions. It also keeps some data secret: it stopped selling its data to outside aggregators to protect its advantage.

Vocabulary

Key Terms

Want every term from every module in one place? Try the searchable glossary.

Big Data
Huge, often unstructured datasets too large for traditional tools to handle easily.
Analytics
Using data, statistics, and models to drive decisions and actions.
Business intelligence (BI)
Reporting, data exploration, queries, and analysis that support decisions.
Data
Raw facts and figures.
Information
Data in context that answers a question or supports a decision.
Knowledge
Insight gained from experience and expertise.
Database
A single table or a collection of related tables.
Table (file)
A list of data arranged in columns (fields) and rows (records).
Field (column)
One category of data in a table, like last name or date of birth.
Record (row)
One instance of whatever a table tracks, like one student or one sale.
Relational database
The most common database type, where tables are linked through shared keys.
Primary key
A field that uniquely identifies each record in a table.
SQL
Structured Query Language: the standard language for creating and querying databases.
Database administrator (DBA)
The person responsible for designing, securing, backing up, and maintaining databases.
Transaction processing system (TPS)
A system that records business transactions like sales, withdrawals, or returns.
Loyalty program
Rewards that encourage repeat purchases and let a firm track customer activity.
Data aggregator
A firm that collects data and resells it.
Legacy system
An older system that's often incompatible with newer technology.
Data warehouse
A set of databases combined and cleaned to support decision-making.
Data mart
A smaller data warehouse focused on one department or problem.
Data lake
Storage that holds both structured and raw, unstructured data for Big Data analysis.
ETL
Extract, transform, load: pulling data from many sources, cleaning it, and loading it into one place.
Dashboard
A visual display of key metrics for a quick read on performance.
Data mining
Using computers to find hidden patterns and build models from large datasets.
Over-engineering
Building a model so tightly fit to old data that it fails on new data.
Dynamic pricing
Changing prices in real time based on demand and other conditions.
