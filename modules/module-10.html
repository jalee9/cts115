The Big Picture

  • Software has near-zero marginal cost: once it's built, each extra copy costs almost nothing. Add network effects and switching costs, and you get a huge industry.
  • Open source software is free and anyone can modify it. It powers much of the Internet, and firms still find ways to make money from it.
  • Cloud computing lets firms rent software (SaaS), platforms (PaaS), or infrastructure (IaaS) instead of owning it.
  • Virtualization makes one computer act like many, which is the technology that makes the cloud efficient.
  • Every software need comes down to a choice: make, buy, or rent.

Section 10.1

A Software Industry in Flux

Software is a great business: building the first copy is expensive, but each additional copy has almost no marginal cost. Combine that with network effects and switching costs, and firms like Microsoft became giants. Now four shifts are shaking up the industry: open source, cloud computing, virtualization, and app stores.

Sections 10.2–10.5

Open Source: Free Software That Runs the World

Open source software (OSS) is free, and its code is public, so anyone can inspect, use, or improve it. Volunteers and paid developers around the world build it together. Examples include Linux (an operating system), Firefox, Android's core, and Python.

Key concept · Software stacks: LAMP and MEAN

A stack is the set of software used to build a system, from the front-end (what users see) to the back-end (server code). Two popular all-open-source stacks:

LAMP = Linux + Apache web server + MySQL database + PHP/Python/Perl.
MEAN = MongoDB + Express.js + Angular + Node.js (all JavaScript-based).

Why firms choose open source

Benefit

Cost

No license fees. That's especially valuable when running thousands of servers.

Benefit

Reliability & security

Many eyes reviewing the code can find and fix bugs quickly. Some versions are security-focused (“hardened”).

Benefit

Scalability

Proven to handle huge workloads at firms like Google and Meta.

Benefit

No lock-in

Firms can modify the code and aren't stuck with one vendor.

Watch out · Heartbleed

In 2014, a serious bug was found in OpenSSL, open source encryption software used by much of the web. It had gone unnoticed for about two years, and the project was maintained by just a handful of people with little funding. “Many eyes” only help if people actually look. Open source also carries legal risks if license rules aren't followed.

How do you make money on free software?

Firms like Red Hat sell support, training, and certified versions. Others sell hosted (cloud) versions, premium add-ons, or hardware. Contributing to open source also helps firms like IBM and Google shape industry standards.

Sections 10.6–10.9

Cloud Computing: Why Buy When You Can Rent?

Cloud computing replaces hardware or software you own with services delivered over the Internet. The three main service models differ in how much the provider manages for you:

Service model examples
ModelYou getExamples
SaaSReady-to-use software in a browser or appSalesforce, Microsoft 365, Gmail, Zoom
PaaSTools and hosting to build and run your own appsGoogle App Engine, Heroku, Azure App Service
IaaSRaw servers, storage, and networking you configureAWS EC2, Microsoft Azure VMs, Google Compute Engine
SaaS upside

Lower costs, faster start

No servers to buy and no installs. Updates are automatic, and you pay as you go. Vendors get steady subscription revenue and serve vertical niches cheaply.

SaaS risks

Less control

You depend on the vendor's reliability, security, and survival. Outages, data lock-in, and limited customization are real risks. Negotiate a strong SLA.

Deployment models

  • Public cloud: shared infrastructure from a provider like AWS, Azure, or Google Cloud.
  • Private cloud: cloud-style computing that one organization uses alone.
  • Hybrid cloud: a mix of both. Firms can cloudburst into the public cloud when demand spikes, such as during a black swan event nobody predicted.
Industry impact

The cloud lowers barriers to entry (startups rent world-class computing), shifts spending from hardware to services, and changes the IT skills employers want. It also fuels the AI boom, since most AI models run in giant cloud data centers.

Section 10.11

Virtualization: One Computer Acting Like Many

Virtualization software lets one physical computer run several “virtual” computers, each with its own operating system and apps. Servers that once sat mostly idle can now be fully used.

Benefit

Fewer machines

Lower hardware, energy, and space costs.

Benefit

Flexibility

New “servers” can be created in minutes and moved between machines.

Variation

Containers

Lighter-weight virtualization that shares one OS while keeping apps isolated. Tools like Kubernetes manage them.

Variation

Virtual desktops

Your “PC” runs on a server, and your device just shows the screen.

Sections 10.12–10.13

App Stores, and the Make, Buy, or Rent Decision

App stores transformed software distribution. Developers reach billions of users instantly, and platform owners like Apple and Google take a cut (and set the rules). For any software need, managers face a key choice:

Make, buy, or rent?
OptionBest when…Watch out for…
Make (build it)The software is a source of competitive advantage and needs to be uniqueHigh cost, long timelines, and the need for skilled staff
Buy (packaged software)A proven product fits your needsRivals can buy it too, plus customization and licensing costs
Rent (SaaS or cloud)Speed, low upfront cost, and flexibility matter mostVendor dependence, security, and long-term subscription costs
Think like a manager

Ask: Does this software create our competitive advantage, or is it just a cost of doing business? Build what makes you different. Buy or rent the rest. Always compare total cost of ownership, not just the sticker price.

Vocabulary

Key Terms

Want every term from every module in one place? Try the searchable glossary.

Marginal cost
The cost of producing one more unit. For software, it's close to zero.
Open source software (OSS)
Free software whose code anyone can view, use, and modify.
Linux
A popular open source operating system that runs many servers and devices.
Software stack
The set of software components used to build an information system.
LAMP
An open source stack: Linux, Apache, MySQL, and PHP/Python/Perl.
MEAN
A JavaScript-based open source stack: MongoDB, Express.js, Angular, and Node.js.
Front-end
The client-side code users see and interact with, like a website or app interface.
Back-end
Server-side code and data that users don't see directly.
Framework
Pre-written software components that speed up development.
Scalability
The ability to handle growing workloads without a major rewrite.
Service level agreement (SLA)
A contract that sets a vendor's commitments for uptime, performance, and support.
Vertical niche
A market focused on one specific industry, like legal or healthcare.
SaaS
Software as a service: finished software delivered online by subscription.
PaaS
Platform as a service: cloud tools and hosting for building and running your own apps.
IaaS
Infrastructure as a service: rented servers, storage, and networking that you configure.
Public cloud
Cloud services from a provider's shared infrastructure.
Private cloud
Cloud-style computing resources used by only one organization.
Cloudbursting
Using public cloud capacity to handle sudden spikes in demand.
Black swan
A rare, unpredicted event with a huge impact.
Virtualization
Software that lets one physical computer act like several separate computers.
Containers
Lightweight virtualization that shares an operating system while keeping apps isolated.
